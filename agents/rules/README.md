# Rules — how agents and the repo work

Decisions about the repo itself rather than the lab: who edits what, what a
change must pass, how much access an agent gets. Same format and the same
rule as `agents/decisions/`: the owner decides; an agent proposes a change in
a separate commit.

## Index

- `docs-layout.md` — facts in owner files, reasons in decisions, no spec graph.
- `pull-request-gate.md` — what has to pass before a change merges.
- `agent-access.md` — convenient access for agents; disaster recovery is the safety net.
