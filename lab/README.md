# Lab — what exists and how it works

The human-facing facts about the lab, kept current. History, plans and agent
material are elsewhere (`agents/`).

| Folder | What goes in it |
|---|---|
| `lab/inventory/` | lookup tables: services, hosts, IP addresses. One row per thing (`lab/inventory/README.md`) |
| `lab/systems/` | one page per thing you run: how it works, what never to do to it, its backups (`lab/systems/README.md`) |

Each folder has a `notes/` beside its pages for measurements, reasons and
dates, so the pages stay short. Split a page into its notes; never delete.

Add a page in the folder whose README fits; there is nothing to add at this
level.
